# Administrative boundary data

`islamabad-tehsil.geojson` contains the Islamabad ADM3 (tehsil) polygon,
filtered from the simplified Pakistan ADM3 GeoJSON published by geoBoundaries.
The upstream dataset represents 2017 administrative units and attributes the
boundary source to Pathways Data Pvt. Ltd. / Pakistan Bureau of Statistics.

- Project: [geoBoundaries](https://www.geoboundaries.org/)
- Dataset metadata:
  [Pakistan ADM3 API](https://www.geoboundaries.org/api/current/gbOpen/PAK/ADM3/)
- Upstream GeoJSON:
  [geoBoundaries-PAK-ADM3_simplified.geojson](https://github.com/wmgeolab/geoBoundaries/blob/9469f09/releaseData/gbOpen/PAK/ADM3/geoBoundaries-PAK-ADM3_simplified.geojson)
- Boundary level: ADM3 (tehsil), represented year 2017
- License: Open Data Commons Open Database License (ODbL) 1.0

This is not sector-level data. Cite geoBoundaries and the upstream data
provider when sharing analyses or derived boundary data; consult the ODbL
terms for redistribution and database-share-alike requirements.
